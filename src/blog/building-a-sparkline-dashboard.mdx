Building on the last article, I'll show you how to use the SparkLine component
we built to create a "dashboard" of data points that anyone can quickly
understand with sparklines.

In [the previous
article](https://travishorn.com/build-a-sparkline-vue-component),
we created a [Vue
component](https://vuejs.org/v2/guide/#Composing-with-Components) which accepts
an array of numbers and creates a [sparkline
chart](https://en.wikipedia.org/wiki/Sparkline).

Now, we can make a dashboard with that component.

![A 3 by 3 grid of data sparkline data visualizations, each labeled with a
numeric value and a text label such as "854. Alt
Volts".](./images/9xwEwFH35.webp)

If you don't already have one created, you should create a Vue project with the
[Vue CLI](https://cli.vuejs.org/).

```console
vue create sparkboard
```

Either choose to use default options or customize to your preference.

Once you have a Vue project created, make sure the `SparkLine.vue` component we
created last time is in the `components/` directory. You may choose to [copy it
from the repository on
GitHub](https://github.com/travishorn/vue-sparkline-component/blob/master/src/components/SparkLine.vue).

Next, replace the entirety of `App.vue` with the following.

```vue
<template>
  <div style="width:100px">
    <SparkLine :data="[808, 1475, 1426, 1884, 1396]" />
    <SparkLine :data="[3246, 1941, 2649, 1633, 1262]" />
    <SparkLine :data="[190, 128, 209, 208, 116]" />
  </div>
</template>

<script>
import SparkLine from "./components/SparkLine.vue";

export default {
  name: "App",
  components: {
    SparkLine
  }
};
</script>
```

Note that the arrays of data here are just random numbers I picked. Feel free to
use whatever you'd like. Later we can pull data from external sources.

Run the development server.

```console
npm run serve
```

You can view the project at [http://localhost:8080/](http://localhost:8080/)

![Three mostly horizontal yellow lines, but they rise and fall at different
rates.](./images/5FWVr_sdo.webp)

Great! There's three tiny sparklines just as the code describes.

I don't like putting the data directly into the template, so the first thing
we'll do is move it into the script.

Let's pretend our data comes from a set of sensors. The updated script looks
like this:

```javascript
import SparkLine from "./components/SparkLine.vue";

export default {
  name: "App",
  data() {
    return {
      sensors: [
        [808, 1475, 1426, 1884, 1396],
        [3246, 1941, 2649, 1633, 1262],
        [190, 128, 209, 208, 116]
      ]
    };
  },
  components: {
    SparkLine
  }
};
```

And the template can be modified to loop over this array of sensor data like
this:

```html
<div style="width:100px">
  <div class="sensor" v-for="sensor in sensors" :key="sensor">
    <SparkLine :data="sensor" />
  </div>
</div>
```

So far, no visual change has been made, but moving the data into the script
makes it much more flexible.

Right now, our entire app is 100 pixels wide. Instead, we should remove this
style from the root element.

```html
<div>
  <div class="sensor" v-for="sensor in sensors" :key="sensor">
    <SparkLine :data="sensor" />
  </div>
</div>
```

And instead add it to individual sensor `<div>`s. This requires us to add a
`<style scoped>` section to the bottom of `App.vue`.

```vue
<style scoped>
.sensor {
  width: 100px;
}
</style>
```

Now that we can style each sensor, it's time to add some basic styles.

Some padding, rounded corners, and color will make a big difference.

```css
.sensor {
  width: 100px;
  padding: 20px;
  border-radius: 4px;
  background-color: #313133;
}
```

![The same three yellow lines from earlier, but each is encapsulated in their
own dark background rectangle with rounded corners.](./images/wl4KDKpDe.webp)

I'm a fan of CSS grids. So I'm going to add a class to the root element…

```html
<div class="sensors">
  <div class="sensor <!-- snip -->">
    <!-- snip -->
  </div>
</div>
```

…and give it some grid styles.

```css
.sensors {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  grid-gap: 20px;
}
```

These styles make the sensors show up in a grid that will automatically adjust
for screen size.

We'll also need to remove the `width` from each sensor, and instead add a
`max-width`.

```css
.sensor {
  max-width: 200px;
  padding: 20px;
  /* ... snip ... */
}
```

![The same three spark lines, but they are side-by-side horizontally now with a
bit of spacing between them.](./images/nek3PF0Hu.webp)

The chart itself doesn't need to take up so much of the box. Add a class…

```html
<SparkLine class="sensor-chart" :data="sensor" />
```

…and style it accordingly.

```css
.sensor {
  /* ... snip ... */
  text-align: center;
}

.sensor-chart {
  width: 50%;
}
```

![The same sparklines, but now they only take up half of their containing
rectangle and are centered within them.](./images/zHWyT794_.webp)

Each of these sensors surely has a name. We can add that in the data.

```javascript
data() {
    return {
      sensors: [
        { name: "Alt Volts", data: [808, 1475, 1426, 1884, 1396] },
        { name: "Alt Amps", data: [3246, 1941, 2649, 1633, 1262] },
        { name: "Aux HP", data: [190, 128, 209, 208, 116] }
      ]
    };
  },
```

Since we changed the format of our data, we need to update the template.

```html
<div class="sensors">
  <div class="sensor" v-for="sensor in sensors" :key="sensor.name">
    <SparkLine class="sensor-chart" :data="sensor.data" />
  </div>
</div>
```

Now we can add the name below each chart.

```html
<div class="sensors">
  <div class="sensor" v-for="sensor in sensors" :key="sensor.name">
    <SparkLine class="sensor-chart" :data="sensor.data" />
    <div class="sensor-name">{{ sensor.name }}</div>
  </div>
</div>
```

The font can be a little smaller, too.

```css
.sensor-name {
  font-size: 12px;
}
```

![Text labels have been added below each sparkline. But they are black, making
them hard to read on the dark background rectangle.](./images/vi8XXtOER.webp)

Oops. It's hard to read. We can change the font and color directly in the
`.sensor-name` style, but I know we're going to be adding some more text, so I'm
going to make the change higher up.

```css
.sensors {
  /* ... snip ... */
  font-family: sans-serif;
  color: #d8d9da;
}
```

![The text is now white and easy to read.](./images/cnc15pv3l.webp)

It's starting to come together. How about we show the most recent data point for
each sensor? Note the new lines in bold below.

```html
<div class="sensors">
  <div class="sensor" v-for="sensor in sensors" :key="sensor.name">
    <SparkLine class="sensor-chart" :data="sensor.data" />

    <div class="sensor-value">
      {{ sensor.data[sensor.data.length - 1] }}
    </div>

    <div class="sensor-name">{{ sensor.name }}</div>
  </div>
</div>
```


We can make these numbers bigger as you can imagine they might be valuable to
see at a glance.

```css
.sensor-value {
  font-size: 30px;
}
```

![Numeric values now appear between the sparklines and their text
labels.](./images/cU-CrrPg5M.webp)

Just for personal preference, I'm going to set the entire background to a darker
color. You can place this right alongside `<style scoped>`.

```html
<style>
body {
  background-color: #212124;
}
</style>
```

![The dark-backgrounded rectangles are now set upon a darker containing
background.](./images/qUv6mW1Gh.webp)

It looks good! And the **best** part? Everything is dynamic. You can change the
data and everything updates.

Say you poll for updated data via an API. You simply replace or modify any of
the sensors' `data` properties and the dashboard will update.

Here's some code that adds a random data point to the first sensor's array every
second. It also "caps" the array to the latest 15 values only.

```javascript
setInterval(() => {
  this
    .sensors[0]
    .data
    .push(Math.floor(Math.random() * 800 + 800));

  this.sensors[0].data = this.sensors[0].data.slice(-15);
}, 1000);
```

With that change, the dashboard comes alive!
